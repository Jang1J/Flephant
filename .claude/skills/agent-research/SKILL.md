# Agent Research -- 논문/기술 조사 스킬

프로젝트 관련 학술 논문, 기술 블로그, 오픈소스 구현체를 체계적으로 조사한다.

## 워크플로우

### Phase 1: 조사 범위 정의
1. 사용자 요청에서 핵심 키워드 추출
2. 프로젝트 맥락 파악 (KOSPI 대형주, multi-agent trading, CNN rebound 등)
3. 조사 범위 결정: 논문 / 기술 블로그 / 오픈소스 / 전체

### Phase 2: 조사 실행
1. **학술 논문**: arxiv, Google Scholar 기반 키워드 검색
2. **기술 블로그**: 관련 기술 블로그/미디엄 검색
3. **오픈소스**: GitHub 레포 검색 (유사 프로젝트, 참고 구현체)
4. 각 결과에 대해 제목, 저자, 연도, 핵심 기여, 프로젝트 적용 가능성 기록

### Phase 3: 정리 및 보고
1. 관련도 높은 순으로 정렬
2. 프로젝트 적용 가능성 평가 (적용 가능 / 참고 / 무관)
3. 조사 보고서 출력

## 조사 보고서 포맷

```markdown
## 조사 주제: [주제]

### 핵심 발견
- 발견 1
- 발견 2

### 논문/자료 목록
| # | 제목 | 저자/출처 | 연도 | 핵심 기여 | 적용 가능성 |
|---|------|----------|------|----------|-----------|
| 1 | ... | ... | ... | ... | 높음/보통/참고 |

### 프로젝트 적용 제안
- 제안 1: [근거]
- 제안 2: [근거]
```

## 조사 품질 기준

- 최소 5개 이상의 관련 자료 수집
- 2020년 이후 논문을 우선 (최신성)
- 한국 금융 시장 관련 자료가 있으면 우선 배치
- 프로젝트의 기존 설계(제안서/설계서)와 비교 분석 포함
