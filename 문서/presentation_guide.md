# 발표용 안전한 수치 가이드

> 본 문서는 중간/최종 발표 시 슬라이드에 사용할 수치 및 표현의 안전한 범위를 정의한다.
> 실험 결과가 아직 확정되지 않은 상태에서 과장된 수치를 방지하기 위한 가이드.

---

## 1. 절대 사용 금지 표현

| 표현 | 이유 |
|------|------|
| "수익률 XX%" (구체적 수치) | 백테스트 수익률은 과적합 가능성. 실가격 검증 전 확정 불가 |
| "XX% 정확도" | 이진 분류 정확도는 클래스 불균형 시 의미 없음 |
| "시장을 이긴다" / "알파를 생성한다" | 학술적 검증 없이 사용 불가 |
| "실시간 트레이딩" | 모의투자(paper trading)임을 명시해야 함 |
| "AI가 자동으로 판단" | 규칙 기반 + LLM 보조이며 완전 자율 아님 |

## 2. 안전하게 사용 가능한 수치/표현

### 시스템 규모
| 항목 | 안전한 표현 | 근거 |
|------|------------|------|
| 유니버스 | "KOSPI 대형주 26종목" | universe_v1.csv 확인 가능 |
| DMP 축적량 | "약 400거래일 분량" | artifacts/daily_market_packet/ 실측 |
| 파이프라인 단계 | "7단계 아티팩트 기반" | 설계서 확인 가능 |
| 에이전트 수 | "5개 에이전트 협업" | Data, Strategy, Risk, Backtest, FDA |
| LLM 사용처 | "5개 지점에서 LLM 보조" | TTP, DMP, RC, FDC 등 |

### 모델 성능 (백테스트)
| 항목 | 안전한 표현 | 주의 |
|------|------------|------|
| AUC-ROC | "0.5X~0.6X 수준" | 정확한 수치는 최종 실험 후 기재 |
| Sharpe | "양수/음수 여부만 언급" | 절대값 기재 지양 |
| MDD | "최대 낙폭 XX% 이내" | 백테스트 기간 명시 필수 |
| Win Rate | "baseline 대비 개선/미달" | 상대 비교만 안전 |

### 비교 표현
| 안전 | 위험 |
|------|------|
| "baseline 대비 개선 경향" | "baseline보다 XX% 우수" |
| "6개 baseline과 비교 실험 수행" | "모든 baseline을 초과" |
| "walk-forward 검증 적용" | "과적합 없음" |
| "purge/embargo 적용" | "미래 정보 누출 완전 차단" |

## 3. 발표 시 필수 고지 사항

1. **모의투자 고지**: "본 시스템은 교육/연구 목적의 모의투자 시스템이며, 실제 투자 수익을 보장하지 않습니다."
2. **백테스트 한계**: "백테스트 결과는 과거 데이터 기반이며 미래 성과를 보장하지 않습니다."
3. **LLM 한계**: "LLM 출력은 참고용이며, 최종 판단은 규칙 기반 시스템이 수행합니다."
4. **데이터 기간**: 백테스트 기간과 검증 기간을 반드시 명시.

## 4. 슬라이드별 수치 체크리스트

발표 전 각 슬라이드에서 아래를 확인:

- [ ] 구체적 수익률 수치가 있으면 → 백테스트 기간/조건 명시했는가?
- [ ] "높은/낮은" 같은 비교 표현에 → 비교 대상(baseline)을 명시했는가?
- [ ] 모델 성능 수치 → walk-forward 결과인가, 단일 split 결과인가 구분했는가?
- [ ] "자동화" 표현 → 어디까지 자동이고 어디가 수동인지 명확한가?
- [ ] 그래프/차트 → 축 레이블, 단위, 기간이 명확한가?

## 5. 질의응답 대비 안전한 답변 패턴

| 질문 | 안전한 답변 |
|------|------------|
| "실제 수익률은?" | "paper trading 기반 모의 결과이며, 실거래 수수료/슬리피지 미반영" |
| "왜 이 종목을?" | "KOSPI 시총 상위 26종목으로 유동성과 데이터 품질 확보" |
| "LLM이 핵심인가?" | "핵심은 규칙 기반 리스크 관리이며, LLM은 해석/설명 보조" |
| "과적합 아닌가?" | "walk-forward + purge/embargo + 다중 baseline 비교로 검증" |
| "실전 적용 가능한가?" | "교육/연구 목적 프로토타입이며, 실전 적용에는 추가 검증 필요" |
