# AI 파트가 만드는 영역 시각화

> **주의: 시각화에 적힌 모델명(LightGBM, XGBoost, FinBERT, GPT API 등)은 예시 후보이며, 최종 모델 선택은 다음 회의에서 확정한다.**

## 핵심 요약: AI 파트가 만드는 것 = 3가지 레이어

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  Layer 1.  에이전트 내부 두뇌 (모델)                          │
│  ─────────────────────────────────────                       │
│  각 에이전트 안에 들어가는 실제 AI/ML 로직                     │
│                                                              │
│  ┌────────────┬──────────────┬────────────┬───────────────┐  │
│  │ Data Agent │Strategy Agent│ Risk Agent │Backtest Agent │  │
│  │            │              │            │               │  │
│  │ Rule-based │ ML: LightGBM │ Rule-based │ Rule-based    │  │
│  │ 데이터     │ LLM: FinBERT │ (MVP)      │ 시뮬레이터    │  │
│  │ 파이프라인 │ LLM: GPT     │            │ + 분석 로직   │  │
│  │            │ Synthesizer  │ ML/RL 확장 │               │  │
│  └────────────┴──────────────┴────────────┴───────────────┘  │
│                                                              │
│                                                              │
│  Layer 2.  에이전트 간 계약 (Card Schema + Handoff)           │
│  ──────────────────────────────────────────────              │
│  에이전트끼리 주고받는 구조화된 JSON 카드 설계                  │
│                                                              │
│  DailyMarketPacket → StrategyCard → RiskCard → BacktestReport│
│                                              → FailureCaseCard│
│                                                              │
│                                                              │
│  Layer 3.  실험 인프라 (Ablation + Feedback)                  │
│  ───────────────────────────────────────────                  │
│  시스템 성능을 과학적으로 검증하는 실험 체계                    │
│                                                              │
│  Signal: S0 → S1 → S2 → S3 → S4                             │
│  Risk:   R0 → R1 → R2 → R3                                  │
│  + walk-forward 3-fold + FailureCaseCard feedback             │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```
